# إعداد نموذج طلب الوصول عبر Formspree

النموذج في `site/console/access.html` هو قناة لاستقبال طلب تواصل ومراجعته يدويًا، وليس خدمة إنشاء حساب. لا يُمنح أي دور ولا يُنشأ حساب عند وصول الرسالة. يجب أن يتحقق مسؤول مخول من الهوية والجهة والحاجة ثم يتبع مسار provisioning مؤسسي منفصل.

## الحالة الحالية

التكامل مفعّل في `site/console/access-config.js` على endpoint النموذج الذي ظهر في صفحة Integration لحساب Formspree. تمت الموافقة على إرسال الاسم الوظيفي والبريد المؤسسي والجهة/الوحدة والسبب الاختياري وخانة الموافقة فقط. معرّف النموذج ليس سرًا وسيكون ظاهرًا للعموم ضمن ملفات الموقع.

تعذر التحقق من إعدادات النطاق المستضيف وبريد الاستلام من صفحة Settings خلال جلسة الإعداد؛ لذلك على مالك الحساب مراجعة تقييد النطاق إلى `samertts.github.io` والتحقق من المستلم قبل تعميم رابط النموذج. لم يُرسل أي طلب فعلي أو بيانات اختبار إلى Formspree أثناء التفعيل.

معرّف Formspree الظاهر ضمن عنوان النموذج ليس مفتاحًا سريًا؛ سيظهر ضمن ملفات الموقع العامة. لا تضع أي API key أو رمز مصادقة في هذا الملف أو في مستودع عام.

## إعداد المزود

1. يراجع مالك المنصة تقييد النطاق في لوحة Formspree على أصل الموقع `samertts.github.io`، ويتحقق من البريد المستلم ومن الأشخاص المخولين بمراجعة الطلبات. تجنب توصيل النموذج تلقائيًا بأوراق عمل أو CRM عام قبل تقييم الصلاحيات والاحتفاظ.
2. يراجع إشعار الخصوصية وموافقة مقدم الطلب وإعدادات التخزين والحذف وتوجيه الرسائل في حساب المزود. يحتوي النموذج على مصيدة `_gotcha` وقيود طول الحقول، لكنها لا تمنع كل الرسائل الآلية أو الطلبات المكررة.
3. عند تغيير endpoint مستقبلًا، لا تضع API key أو رمز مصادقة في المستودع. تقبل الواجهة فقط HTTPS وعلى المضيف `formspree.io` ومسار `/f/<id>`، وتظل وسائل الاتصال من JavaScript مغلقة. لا تغيّر المزود أو نطاق CSP دون مراجعة أمنية.
4. بعد التحقق من إعدادات المزود، يمكن إجراء اختبار ببيانات اصطناعية غير شخصية وبموافقة مستقلة قبل استخدام النموذج فعليًا. لا يُرسل اختبار تلقائي من CI. تحقق من رابط GitHub Pages ومن ظهور رسالة استجابة صريحة للمستخدم بعد الإرسال.

الحقول لا تطلب رقمًا وطنيًا أو كلمة مرور أو وثائق أو بيانات حساسة. الإرسال عبر مزود خارجي ينقل البيانات إليه؛ يجب ألا يُفعّل قبل إشعار المتقدم بوضوح وموافقته. لا تستخدم القناة لعمليات تشغيلية حساسة أو قرارات موارد بشرية، ولا تعتبرها نظام تذاكر موثوقًا أو سجل تدقيق. لا تضمن الواجهة وحدها عدم التكرار أو السرية التامة أو زمن التسليم؛ فهذه خصائص تتطلب خدمة خادمية وحوكمة مستقلة.

## الاختبارات والحدود

اختبارات الموقع تتحقق من endpoint العام المعتمد، ومن استمرار بوابات الموافقة والتحقق من الإعدادات ومصيدة spam. لا تختبر إرسالًا حقيقيًا ولا تُرسل بيانات إلى Formspree. النموذج قناة لاستقبال طلبات يدوية فقط، وليس نظام مصادقة أو إنشاء حساب أو سجل تدقيق أو خدمة تشغيلية حرجة.
