# منصة القوى العاملة الوطنية العراقية (INWP)

منصة قيد التطوير لتنسيق خدمات القوى العاملة بين الجهات، مع مراعاة العمل في بيئات اتصال متفاوتة. يحتوي المستودع على نواة backend لمسار الحضور والمزامنة، وتصورات معمارية، وبوابة عامة.

## الحالة الحالية

المشروع **ليس منصة وطنية مكتملة أو جاهزة للإنتاج**. يصف [تقرير التنفيذ](IMPLEMENTATION_REPORT_AR.md) حدود ما يعمل في نواة الحضور والمزامنة وما لم يكتمل بعد، بما في ذلك الهوية وسجل الموظفين والإجازات والرواتب ولوحة التشغيل.

تتضمن البوابة العامة رابطًا إلى [لوحة العرض التوضيحي](https://samertts.github.io/Iraq-National-Workforce-Platform-INWP/console/) ومعرض [وحدات المنصة المقترحة](https://samertts.github.io/Iraq-National-Workforce-Platform-INWP/console/#platform)، وكلاهما يستعمل أمثلة اصطناعية فقط. لا يوجد في العرض تسجيل دخول أو قاعدة بيانات أو اتصال API أو عمليات إدارية؛ لا ترفع إليه بيانات حقيقية ولا تستخدمه لاتخاذ قرارات تشغيلية. صفحة [طلب الوصول](https://samertts.github.io/Iraq-National-Workforce-Platform-INWP/console/access.html) ترسل الحقول المحدودة بعد الموافقة إلى Formspree الخارجي؛ وهي قناة استقبال يدوية لا تنشئ حسابًا ولا توفر مصادقة أو تفويضًا. راجع إعدادات النطاق والمستلم والاحتفاظ لدى Formspree قبل استخدامها مع متقدمين فعليين.

## خارطة التطوير

راجع [خارطة تنفيذ المنصة](docs/IMPLEMENTATION_ROADMAP_AR.md) و[نطاق الوحدات المقترحة ومراحلها](docs/PLATFORM_MODULES_AR.md) للمراحل وبوابات الأمن وسلامة البيانات والقرارات المطلوبة. يوضح [TODO.md](TODO.md) ما هو معرض اصطناعي منجز وما بقي لخدمات backend تشغيلية. الرواتب وسياسات الموارد البشرية تحتاج قواعد معتمدة من مالك العمل؛ لا تُستنتج من الشيفرة.

## التشغيل المحلي

إعداد Compose الحالي مخصص للتطوير والاختبارات المحلية فقط، وليس بيئة staging أو إنتاج. راجع [دليل النشر](PAGES_DEPLOYMENT.md) لحدود GitHub Pages، و[دليل التشغيل العربي](deploy/README.ar.md) لمتطلبات الخدمات الخلفية.
